# matrix-assistant-info
Matrix Assistant is an experimental, privately operated Matrix client that connects an authorized Matrix room to local Codex and Claude Code command-line tools. It is not a public bot service and is not affiliated with Matrix, Element, OpenAI, or Anthropic.

The client is designed to process requests only from an approved user in an approved room. Task text and necessary context are sent to the selected AI providers for processing, and replies are returned to that room. Matrix end-to-end encryption does not prevent the selected AI providers from receiving the task text.

This repository contains public application information only. It does not contain credentials, access tokens, encryption keys, chat logs, or research materials. Live Matrix integration is still undergoing validation.
